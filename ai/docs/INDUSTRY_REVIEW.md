# 산업 분류 세분화 검증

- 작성일: 2026-10-09
- 검증받을 것: **KRX 업종은 뉴스를 종목에 연결하기엔 너무 넓어서 세부 산업으로 나눴다. 나눈 방식과 회사별 연결이 맞는지.**
- 표 구조 등 DB 설계는 [CLASSIFICATION_DB_DRAFT.md](CLASSIFICATION_DB_DRAFT.md) 에 있다. 이 문서에서는 다루지 않는다.

---

## 1. 왜 나누나

산업 뉴스(예: "D램 가격 급등")를 어느 종목 브리핑에 붙일지 정하려면 **회사마다 어느 산업인지** 알아야 한다.
지금 가진 산업 정보는 BE 의 종목 섹터(KRX 업종)뿐인데, 이걸로는 너무 넓다.

**문제 1. 한 업종에 성격이 다른 회사가 섞여 있다**

시가총액 상위 20개 중 "전기전자" 가 6개다.

| KRX 업종 | 회사 | 실제로 반응하는 뉴스 |
| --- | --- | --- |
| 전기전자 | SK하이닉스 | 메모리 가격 |
| 전기전자 | LG에너지솔루션 · 삼성SDI | 배터리 수요 |
| 전기전자 | 삼성전기 | 전자부품(MLCC) |
| 전기전자 | 삼성전자 | 메모리 · 스마트폰 · 가전 |

KRX 업종 그대로 쓰면 배터리 기사가 SK하이닉스 브리핑에, D램 기사가 LG에너지솔루션 브리핑에 붙는다.

**문제 2. KRX 업종이 실제 사업과 다른 회사가 있다**

| 회사 | KRX 업종 | 실제 |
| --- | --- | --- |
| SK스퀘어 | 금융 | SK하이닉스 지분을 가진 지주회사. 주가가 하이닉스를 따라간다 |
| 삼성물산 | 유통 | 건설·상사 + 삼성 계열사 지분을 가진 지주 역할 |

## 2. 어떻게 나눴나

- **맨 위는 KRX 업종을 그대로 둔다.** BE 화면에 보이는 섹터와 어긋나지 않게 하기 위해서다.
- **그 아래에 뉴스 연결용 세부 산업을 둔다.**
- 회사는 세부 산업에 연결한다. 한 회사가 여러 세부 산업에 속해도 된다.
- 회사의 화면 섹터(KRX)와 뉴스 연결용 산업은 달라도 된다. 예를 들어 SK스퀘어는 화면 섹터가 금융이지만 메모리반도체에도 연결한다.
- 기사가 넓게 말하면 넓게, 좁게 말하면 좁게 붙는다.
  - "반도체 업황" 기사 → 반도체 아래 회사 전부
  - "D램 가격" 기사 → 메모리반도체 회사만

```
전기전자
 ├─ 반도체
 │   ├─ 메모리반도체      (D램, 낸드, HBM)
 │   └─ 파운드리          (위탁생산, 시스템반도체)
 ├─ 스마트폰
 ├─ 가전                 (TV, 생활가전)
 ├─ 전자부품              (MLCC, 카메라모듈, 반도체 기판)
 └─ 2차전지              (배터리셀)
운송장비·부품
 ├─ 자동차
 ├─ 조선
 └─ 방산·항공우주
제약
 └─ 바이오의약품          (위탁생산, 바이오시밀러)
금융
 ├─ 은행
 └─ 지주회사
보험
 └─ 생명보험
기계·장비
 └─ 발전설비              (원전, 가스터빈)
건설
 └─ 건설
```

## 3. 회사별 연결 — 확인해 주세요

대상: 코스피 시가총액 상위 20개(BE `MVP_STOCKS`, 2026-10-06 기준).
"연결할 산업" 은 사업보고서로 확인하기 전의 초안이다.

**확인 방법**
1. DART(dart.fss.or.kr)에서 회사의 최신 사업보고서를 열고 **"II. 사업의 내용"** 을 본다.
2. 주요 사업이 "연결할 산업" 에 다 들어 있는지, 관계없는 산업이 들어 있지 않은지 본다.
3. 기준: **그 산업 뉴스가 나오면 이 회사 주가가 같이 움직이는가.** 움직이면 연결한다.
