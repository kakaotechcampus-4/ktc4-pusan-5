# 판정 품질 채점 결과

분류 ④ 판정(종목에 넘길지)을 정답 라벨과 맞춰 본 결과다. 정답 라벨은 사람이 아니라 외부 모델이 만들었다.
만든 방식과 한계는 [README](README.md#정답-라벨은-어떻게-만들었나)에 있다.

## 읽는 법

- **넘김 일치**: 정답이 "넘김(D·I)"인지 "안 넘김(N)"인지를 맞힌 수. 보고서에 들어가느냐가 서비스에 영향을 주는 값이라 이것을 주로 본다.
- **정확히**: D·I·N 라벨까지 맞힌 수.
- 정답이 U(판단할 수 없음)인 줄은 채점에서 뺐다.
- 표본은 무작위가 아니라 **방식끼리 답이 갈린 칸에서 더 많이 뽑았다.** 그래서 절대 정확도가 아니라 방식끼리의 비교로만 읽는다.

## 원칙: 규칙을 정한 데이터와 확인한 데이터를 나눴다

규칙·문턱을 고를 때 본 정답으로 다시 채점하면 점수가 좋게 나온다. 그래서 바꾼 규칙은 **그 뒤에 새로 수집한 날짜**의 정답으로 확인했다.

| 날짜 | 이 데이터로 한 일 |
| --- | --- |
| 10월 말·11-05 | 판정 방식 후보 설계 (이 폴더에 없음) |
| 11-06 기사 | 판정 구조 결정: 회사·산업은 luna, 관계는 Jev |
| 11-08~09 | 결정한 구조를 처음 보는 데이터로 확인 |
| 11-09 오후 | 관계 질문 문안 고친 것 확인 |
| 11-10 | 경쟁 관계 범위 넓힌 것 확인 |

## 1. 판정 구조: 관계 경로를 luna 에서 Jev 로 (11-06 기사, `gold/labels_20261106.csv`)

| 방식 | 넘김 일치 (79) | 정확히 (79) | 판정 비용 |
| --- | --- | --- | --- |
| luna 하나로 전부 | 67 | 57 | ₩70.74 |
| **회사·산업 luna + 관계 Jev (실제 코드)** | **75** | **71** | **₩53.33** |

- 관계 경로만 보면 luna 20/29, Jev 26/29 (같은 구조의 시뮬레이션).

**같은 입력을 두 번 돌렸을 때 넘김 여부가 바뀐 비율** (11월 814쌍, 정답 없이)

| 경로 | luna | Jev |
| --- | --- | --- |
| 회사 (212) | 0.5% | 0% |
| 산업 (332) | 2.1% | 0% |
| 관계 (270) | **25.9%** | 1.1% |

## 2. 처음 보는 데이터로 확인 (11-08~09, `gold/labels_20261108-09.csv`)

정답 94쌍 중 U 17 을 빼고 77쌍.

| 경로 | luna 하나로 전부 | 회사·산업 luna + 관계 Jev |
| --- | --- | --- |
| 회사 (13) | 12 | 13 |
| 산업 (14) | 11 | 10 |
| 관계 (50) | 28 | **37** |
| 합 (77) | 51 | **60** |
| 판정 비용 | ₩122.23 | ₩70.75 |

- "○○가 이 회사의 주주"뿐인 관계 6쌍(정답 모두 N): luna 0/6, 코드 규칙 6/6.

## 3. 관계 질문 문안 고치기 (11-09 오후, `gold/labels_20261109pm.csv`)

정답 53쌍 중 U 1 을 빼고 52쌍. 모두 관계 경로.

| 방식 | 맞은 수 (52) |
| --- | --- |
| 고치기 전 | 25 |
| 홍보성 문턱 0.9 → 0.7 + 스포츠 구단 예시만 | 30 |
| **+ 경쟁사 질문 1판 (채택)** | **43** |
| + 경쟁사 질문 2판 | 39 |

## 4. 경쟁 관계 범위 넓히기 (11-10, `gold/labels_20261110.csv`)

정답 49쌍 중 U 3 을 빼고 46쌍. 그중 관계 판정 39쌍, 홍보성 7쌍.

| 방식 | 관계 맞은 수 (39) |
| --- | --- |
| 고치기 전 문안 | 21 |
| 경쟁사 질문 1판 | 24 |
| **1판 + 넓힌 범위 (채택)** | **28** |

- 홍보성 문턱 0.7 로 새로 빠진 7쌍: 7쌍 모두 빼는 게 정답.
- 남은 약점: 경쟁사의 전사 실적·이익 전망 숫자만 있는 문장을 경쟁 변화로 읽는다(틀린 11쌍 중 7쌍).

## 5. 관계 범위 문구 정리 (PR #115 리뷰 반영, 위 3·4의 정답 다시 사용)

| 정답 | 고치기 전 | 고친 뒤 |
| --- | --- | --- |
| 11-09 오후 47쌍 | 41 | 39 |
| 11-10 39쌍 | 24 | 32 |
| 합 86 | 65 | **71** |

- 같은 문안을 다시 돌려도 11-09 오후는 38 ↔ 41 로 3쌍 흔들린다. −2 는 흔들림 안이고 +8 은 흔들림보다 크다.
- 이 표는 이미 본 정답을 다시 쓴 것이라 새 날짜 확인은 아직 없다.
